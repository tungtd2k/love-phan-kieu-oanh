# Dành riêng cho Phan Kiều Oanh 💌

Website tĩnh độc lập, không cần cài package hay framework.

## Chạy thử

Mở trực tiếp `index.html` bằng trình duyệt, hoặc dùng bất kỳ static hosting nào như GitHub Pages, Netlify hay Cloudflare Pages.

Sau khi xác nhận, website gửi ngày, giờ và món đã chọn qua email đến chủ website. Nếu dịch vụ gửi email tạm thời không phản hồi, người dùng vẫn có thể dùng nút sao chép để gửi thủ công.
